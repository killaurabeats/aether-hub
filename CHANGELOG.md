# Changelog

Все заметные изменения Aether Hub. Формат вдохновлён Keep a Changelog,
версии соответствуют тегам репозитория (`v1.3.0` → `1.3.0`).

CI автоматически берёт секцию текущей версии из этого файла и подставляет её
в `latest.json` (поле `notes`) и в описание GitHub Release.

## [Unreleased]

## [1.3.1] - 2026-11-21

### Интерфейс

- **Боковое меню очищено.** Убран блок Creator Mode / режим пользователя;
  компактный переключатель «Админ / Юзер» перенесён в профиль и показывается
  только администратору. Перед Samples & Loops добавлен тонкий разделитель.
- **Центрирован логотип.** Иконка с глазами теперь строго по центру квадратной
  рамки без смещения и лишнего кропа.
- **Главный экран стал компактнее.** Hero-баннер ниже по вертикали, убраны
  подзаголовки «Ручной выбор команды Aether» и «Обновляется из облака…»,
  нижние карточки лицензии/установок удалены, футер оставлен лаконичным.
- **Единые карточки каталога.** Все карточки плагинов получили фиксированную
  высоту и одинаковые пропорции обложки (`aspect-ratio` + `object-cover`).
- **BETA-превью под замком.** Обложки BETA-плагинов в каталоге и окне релиза
  размыты (`blur(16px)` + затемнение) с золотым замком «BETA • В разработке».
- **Чистое окно BETA-плагина.** Скрыты звёзды рейтинга и блок Machine ID/HWID;
  остаются установка для Beta-тестеров или плашка с замком и ссылкой в профиль.
- **SOON-экраны без фильтров.** В пустых Drumkits и Presets скрыта панель
  «Все / Установленные / Новые / Рейтинг».
- **Samples & Loops.** Убран дублирующий заголовок над баннером, вместо
  горизонтальных типов — компактный dropdown категорий (Loops, One-Shots, FX,
  Vox, Drums, Bass/808, Melodies), те же категории добавлены в форму загрузки.
  Нижняя рамка про премодерацию заменена иконкой-подсказкой «?».
- **Профиль и настройки.** Убрана дублирующая кнопка копирования Machine ID,
  упрощён блок «Связь». В «Виде» появились три рабочие темы: **Aether Purple**,
  **Pitch Black** и **Clean Light** с сохранением в localStorage. Вкладка
  «Облако» скрыта от обычных пользователей и видна только в админ-режиме.
- **Уведомления.** Элементы колокольчика открывают модальное окно с полным
  описанием релиза/апдейта и кнопкой перехода к плагину.

### Техническое

- Категории сэмплов расширены в Supabase (`loop`, `oneshot`, `fx`, `vocal`,
  `drums`, `bass`, `melody`), обновлены RPC-валидация и типы фронтенда.
- `latest.json` и GitHub Release продолжают автоматически брать release body
  из актуальной секции `CHANGELOG.md`.

## [1.3.0] - 2026-11-21

### Добавлено

- **BETA-ранний доступ.** Новый уровень `tier = beta` в каталоге и Admin Studio
  (порядок FREE → PRO → BETA). Бейджи BETA и BETA TESTER светятся фирменным
  золотым неоном; установка открыта только для HWID с активированным
  Beta-инвайтом. При наличии инвайта BETA-лицензия выдаётся и записывается
  автоматически, без инвайта показывается золотая плашка
  «В разработке • Доступно только Beta-тестерам».
- **AetherSaturator v1.0.0-beta под замком.** Ранний доступ к сатуратору:
  macOS VST3 + AU и Windows VST3, отдельная обложка и публикация в Supabase
  со статусом `tier = beta`. Windows-сборка собрана CI в приватном
  репозитории `aether-saturator`.
- **Samples & Loops от комьюнити.** Новый раздел с лупами и ваншотами,
  фильтрами по типу, BPM и тональности, вкладками «Все», «Топ недели» и
  «Выбор комьюнити». Встроенный waveform-плеер с мгновенным превью и
  авто-стопом предыдущего трека.
- **Нативный Drag & Drop в FL Studio / DAW.** Файл сэмпла кэшируется локально
  и передаётся через нативный file-drag Tauri — луп можно перетащить прямо
  на плейлист. Загрузка `.wav` / `.mp3` проходит премодерацию, а в Admin Studio
  появились прослушивание, «Одобрить», «Отклонить», «В выбор комьюнити» и
  «Удалить».
- **Колокольчик уведомлений.** Иконка в верхней панели со счётчиком
  непрочитанных: свежие релизы, обновления BETA, статусы одобрения
  PRO-лицензий и результаты модерации загруженных сэмплов.
- **Zero-Copy лицензии PRO.** После одобрения заявки (вручную или через
  выборочную автовыдачу) кнопка «Запросить» превращается в
  «Активировать и установить», а `license.aether` автоматически записывается
  в системную папку лицензий плагина — без ручного копирования.
- **Универсальный авто-деплой плагинов.** `scripts/deploy-plugin.sh` (и копия
  в `~/Desktop/OpenCode Project/AetherPlugins/`) упаковывает актуальные
  macOS/Windows-билды, загружает их в Supabase Storage и обновляет запись
  в таблице `releases` одной командой.

### Исправлено

- **Дубли VST3 на Windows.** При установке и обновлении проверяются обе папки —
  `%LOCALAPPDATA%\Programs\Common\VST3` и
  `C:\Program Files\Common Files\VST3`; старые одноимённые копии удаляются,
  чтобы FL Studio подхватывала свежую версию.
- **Автообновление.** `latest.json` и описание GitHub Release теперь берут
  реальный список изменений из `CHANGELOG.md` для текущего тега, а не
  захардкоженную строку.

### Техническое

- Edge Function `aether-admin`: поддержка `tier = beta`, автоматическая
  BETA-лицензия по инвайту и модерация `community_samples`.
- Supabase: таблица `community_samples`, bucket `aether-samples`, RPC для
  загрузки/лайков/скачиваний и RLS-политики.
- Версия лаунчера поднята до `1.3.0` в `package.json`, `tauri.conf.json`
  и `Cargo.toml`.
