# Aether Hub - правила для агентов

## Описания релизов - строгое правило

Перед публикацией или обновлением любого релиза в Supabase (`releases`) или
Admin Studio обязательно прочитайте и соблюдайте
[`docs/RELEASE_DESCRIPTIONS.md`](docs/RELEASE_DESCRIPTIONS.md).

Коротко:

- описание - **2 коротких живых предложения**, понятных музыканту;
- **никогда** не писать технические детали реализации: названия C++/DSP
  библиотек и движков (например, `Signalsmith Stretch`), `биквады`, `PDC`,
  `C++`, внутренние модули и т.п.;
- **никогда** не дублировать форматы и платформы (`VST3`, `AU`, `macOS`,
  `Windows`) - они уже указаны внизу карточки;
- **никогда** не превращать описание в ченджлог, список изменений или
  перечисление ручек;
- использовать только короткий дефис `-`; длинные тире (em dash и en dash)
  запрещены.

Это правило действует для всех будущих релизов и для обоих языков (`RU`/`EN`).
